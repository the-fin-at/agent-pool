Bekannte reine Mockup-Abweichungen für einen späteren Nachbau: plattformspezifische Fenster-Buttons bereinigen; wöchentliche Beschriftungen und Resets korrekt zuordnen; keine erfundenen absoluten Stundenbudgets übernehmen. Der Produktname lautet Agent Fleet.
