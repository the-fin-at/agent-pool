Set up with your agent

Clone https://github.com/the-fin-at/agent-pool and read README.md and skills/setup-agents-fleet/SKILL.md. Set up the current main-branch CLI, desktop app where supported, and the agent-fleet and setup-agents-fleet skills for my operating system. Check build prerequisites and preserve existing accounts and data. Guide me through my own provider login, then verify the installation with doctor and monitor --refresh.

Build from source

For the native CLI, install Git and Rust 1.96.1. The desktop build also needs Node.js 24 and your platform's Tauri prerequisites.

git clone https://github.com/the-fin-at/agent-pool.git
cd agent-pool
cargo build -p fleet-cli --release --locked
sh scripts/install_native.sh
export PATH="$HOME/.local/bin:$PATH"
agent-fleet doctor

Commands above are for macOS and Linux. Use the PowerShell installer on Windows.
