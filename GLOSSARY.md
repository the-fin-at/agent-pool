# Agent Fleet glossary

- **Pool**: one Unix user's private queue, profiles, quotas and reports on one machine.
- **Connection**: a client-side SSH destination plus the server executable and pool path.
- **Profile**: one provider-specific native account directory and scheduling configuration.
- **Worker**: one persistent executor for a pool, independent of any client connection.
- **Workspace**: a named, existing directory on the executing server.
- **Login session**: a bounded native provider login, with browser consent performed on the client.
- **Controlled provider**: a test CLI that simulates native output without inference or real credentials.
- **Loop**: an observed baseline, a fault/user/performance scenario, a fix if required, then re-verification at the same public interface.
